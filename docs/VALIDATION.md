검증은 잘못된 ID·중복·빈 선택·세 곳 초과, 지역·유형·존재 여부, 잘못된 좌표·이미지·HTML, 외부 조회 실패를 포함한다. 최종 AI 근거 요청은 여러 장소를 한 번에 보내며 소개 원문에 없는 구절은 채택하지 않는다.

지역 검증은 강원도 전체 검색에서 시군 코드 생략, 선택한 시군의 실제 주소 대조, 잘못된 시군의 외부 호출 전 거절을 포함한다. 서로 다른 국문·연관 서비스 코드를 혼용하지 않는지 검사한다. 연관 후보는 전체 이름을 정규화한 단일 장소만 연결하고, 동명 장소가 둘이면 연결하지 않는다. 띄어쓰기 보조 검색에서도 이 조건을 유지한다.

사진은 촬영지·이미지 주소를 검증하며 관광 장소 ID나 정확한 좌표를 만들어내지 않는다. 오디는 관광지명·언어·제공 위치를 대조하고 원문을 정리한다. 추가 관광 서비스가 실패해도 기본 장소 상세 조회가 유지되는지 검사했다. 먼 코스의 안내는 직선거리이며 이동시간을 창작하지 않는다.

추가 자료의 검색 결과 없음과 검색 결과는 있지만 대조 조건 불일치로 채택되지 않은 경우를 이야기·연관 각각에서 검사했다. 네 사례 모두 HTTP 200과 빈 목록·원인 안내를 반환하며 기본 장소 소개는 유지된다.

무장애 정보는 동일 ID라도 이름·주소·유형·제공 위치가 다른 자료의 연결을 거절한다. 이름 검색 때 별도 지역코드를 사용하고 다른 서비스 ID로 동일 장소를 확인한 경우만 세부 자료를 연결한다. 동명 ID의 중복, 다른 ID의 세부 응답, 빈 항목, HTML 원문 정리, 잘못된 입력, 추가 조회 실패 시 기본 상세 유지도 모의 검증했다.

## 실제 외부 연결

자동차 경로를 내부 ASGI API에서 실제 관광·카카오 API로 검증했다. 강원숲체험장 `12_2610850`과 가보자순대국 `39_2891703`을 국문 서비스로 재확인한 뒤 HTTP 200, 거리 16,693m, 예상 1,505초, 도로 좌표 286개를 확인했다. 예상 시간은 조회 시점에 따라 달라진다. 서버를 별도 실행한 공개 운영 검증과는 구분한다.

경로 모의 검증에는 잘못된·중복·초과 ID, 브라우저 좌표 입력 거절, 강원도 밖 장소 거절, 좌표 누락 시 부분 성공 유지, 인증 오류·원문 비밀 값 노출 방지, 단위·음수 시간·경로 좌표 오류 거절, 시간 초과·하루 상한·한 장소 코스, 같은 구간 캐시와 반대 방향 별도 조회가 포함된다.

| 프런트 내부 연결 | 상태·지역·이야기·연관 API의 HTTP 200 확인 |

이전 최소 확인에서 사진 검색 전체 9,607건, 춘천 오디 14건, 춘천 연관 1,321건의 응답 수를 확인했다. 이 수치는 요청 조건의 검색 건수이며 고유 관광 장소 수나 연결 성공 수가 아니다. 일부 관광사진의 제공 주소는 로드되지 않아 사진 누락 안내를 표시한다.

추가 자료 누락 점검에서 계방산(평창)·강원수산횟집·2018 평창동계올림픽대회 및 동계패럴림픽대회 기념관의 이야기·연관 조회는 모두 HTTP 200·연결 자료 0개였다. 계방산 오디 이름 검색은 0건, 연관 이름 검색은 중심 관광지명이 계방산오토캠핑장인 3건이어서 계방산 자료로 채택하지 않았다. 평창 지역 오디에는 별도 장소의 자료가 있고, 연관 API의 올림픽 검색에는 평창올림픽기념관이라는 이름이 나타났다. 공식 이름과 별칭의 동일 장소 검증이 없는 자료는 임의로 연결하지 않는다. 비교용 춘천향교는 이야기 1개·연관 후보 5개·국문 연결 장소 1개를 다시 확인했다.

실제 관광 API는 사용자 설정으로 호출했다. 실제 인증키·인증 URL은 출력하지 않았다. 국문 서비스의 기존 인증 설정은 유지하고 별도 세 서비스의 설정을 서버에서 읽는다.

## 화면 확인

- 사용자 관점 점검에서 저장 코스를 열어 실제 장소 재조회·기존 방문 체크와 메모 표시를 확인했다. 현재 저장소는 최근 코스 한 개이며, 상세 추가 콘텐츠는 탭을 다시 열 때 새로 조회한다. 자료 상태 표시·결과 유지·저장 교체 안내·식당 이용정보는 다음 보완 제안으로 README에 구분했다.
- 상세의 선택 버튼 위에 마우스를 올리면 일반 보조 버튼의 밝은 배경이 선택 색상을 덮어 흰 글자가 읽기 어려워지는 문제를 수정했다. 실제 ‘이야기 듣기’ 버튼의 마우스 올림 상태에서 수정 전 배경 `rgb(240, 244, 250)`·흰 글자, 수정 후 배경 `rgb(20, 80, 82)`·흰 글자를 확인했다. 현재 선택된 항목의 글자가 표시됐다.

- 관광사진 카드를 제목·촬영지·시군 기준으로 묶었다. 강원도 전체·기본 키워드 ‘강원’의 실제 결과에서 박물관 이미지 5개가 로드에 실패해 해당 카드가 사라지고 작은 제외 안내가 표시됐다. 영시암 한 장과 인제군 설악산 여섯 장은 각각 한 카드로 표시됐다. 다음·이전 버튼으로 이미지 주소와 사진 번호가 바뀌고, 조건 탭으로 이동했다 돌아와도 사진과 제외 안내가 유지됐다.
- 같은 검색에서 ‘사진 더 보기’를 눌러 속초시 설악산 사진 12장 묶음이 추가되는 것을 확인했다. 인제군·속초시의 설악산은 촬영지가 달라 별도 카드로 표시됐으며 이전 두 카드와 실패 사진 제외 기록이 유지됐다. 박물관 이름만 새로 검색했을 때는 사진 5개가 모두 실패해 빈 카드 없이 조건 변경 안내가 표시됐다.
- 인제군·설악산을 별도로 검색하면 영시암 한 장과 설악산 아홉 장이 두 카드로 표시됐다. 설악산 두 번째 사진을 선택하고 추가 조회했을 때 같은 묶음이 21장으로 늘고 두 번째 사진의 이미지 주소·선택이 유지됐다.
- 추가 조회 후 사진 묶음 화면을 320·375·768·1280px에서 확인했다. 모바일 한 열·768px 두 열·1280px 세 열이며 가로 넘침은 없었다. 사진은 `contain`으로 전체 비율을 유지했고 사진 넘기기 버튼은 44×44px였다. 카드 수가 적으면 데스크톱의 남는 열을 접어 카드가 가용 폭을 사용하도록 했다.

- 홈은 전체 폭 검색 영역의 조건·문장·사진 세 탭으로 개편했다. 초기 조건 선택, 한 패널만 표시, 탭 전환 후 지역·키워드·문장 유지, 방향키·Home 이동, 직접 조건 선택 후 편집 제목 초점을 확인했다. 문장 해석 미연결 상태에서 준비 중 안내와 수동 선택 버튼을 확인했으며 실제 LLM 성공 흐름은 미검증이다.
- 펼친 키워드 입력과 사진 검색 결과를 320·375·768·1280px에서 확인했다. 모바일은 지역·유형 한 열, 검색 버튼 전체 폭, 지역 바로가기 2×2이며 768px 이상에서는 지역·유형 두 열, 검색 버튼 오른쪽, 지역 버튼 한 행이다. 가로 넘침은 없었고 모바일 탭 이름은 한 줄로 표시됐다.
- 새 사진 탭에서 인제군·설악산을 명시적으로 검색해 10장의 이미지 로드를 확인했다. 다른 탭에 갔다 돌아와도 조건과 사진 결과가 유지됐다. 사진 결과는 모바일 한 열·768px 두 열·1280px 세 열이었다. 새 조건 폼에서 춘천시 실제 후보 18개 조회·강원숲체험장과 가보자순대국 선택·코스 생성·결과 제목 초점 이동도 확인했다.
- 개편한 홈에서 춘천시 버튼을 눌러 실제 관광 후보 18개로 이동했다. 강원숲체험장과 가보자순대국을 담고 코스 재검증·여행 시작·방문 체크에 따른 다음 장소 전환·메모 저장·새로고침 후 코스와 기록 복원을 확인했다. 순서를 바꿔도 방문 체크와 메모가 유지됐고 모든 장소 체크 시 여행 완료 안내를 확인했다. 이는 UI 검증용 직접 체크이며 실제 방문 인증이 아니다.
- 개편 코스 화면은 320·375px에서 한 열과 여행 중 하단 길찾기, 768·1280px에서 목록·지도 두 열을 확인했다. 가로 넘침은 없었다. 직전 코스 장소를 출발지로 전달하는 실제 카카오맵 링크도 확인했다.
- 자동차 이동 확인을 실제 브라우저에서 실행해 강원숲체험장 → 가보자순대국의 예상 26분·16.7km와 지도 배경·파란 도로 실선을 확인했다. 시간은 조회 시점에 따라 달라진다. 순서를 바꾸면 이전 합계와 도로 실선이 사라지고 방문 순서 점선만 표시됐으며 외부 길찾기의 출발지·목적지도 바뀌었다.
- 지도 위 휠 입력으로 페이지를 내릴 때 확대·축소가 실행되던 문제를 수정했다. 수정 후 휠 입력 전후 지도 타일 축척이 유지됐고 + / − 버튼을 통한 조작 안내를 표시했다. 지도 크기 변경 시 장소와 도로 경로를 다시 맞춘다.
- 실제 도로를 조회한 코스에서 320·375·768·1280px로 폭을 바꿔 이동정보와 지도 배치를 확인했다. 모바일은 목록 다음 지도, 768px 이상은 목록·지도 두 열이며 가로 넘침이 없었다. 크기 변경 후 두 장소 마커가 모두 지도 영역 안에 표시됐다.

- 가원습지 상세의 ‘방문 편의정보’에서 접근로·출입구·보조견 동반 항목과 출처·장소 자료 수정일을 확인했다. 375px 모바일에서 네 상세 버튼이 두 줄로 배치되고 가로 넘침 없이 표시됐다. 춘천향교의 편의자료 없음 안내와 장소 소개 복귀도 확인했다.
- 계방산 상세에서 이야기 검색 결과 없음과 연관 대조 조건 불일치 안내가 각각 표시되는 것을 확인했다. 두 영역의 조회 완료·자료 없음 표시와 장소 소개로 돌아가는 버튼이 동작했다.
- 장소 카드·상세 화면·관광사진 목록은 원본 비율을 유지하는 `object-fit: contain`으로 사진 전체를 표시한다. 프레임과 사진의 비율이 다르면 남는 공간에 연한 배경을 표시한다. 평창군의 실제 계방산·음식점·올림픽 기념관 사진에서 잘림 없이 표시되는 것을 확인했다.
- 사진 탐색에 촬영지·촬영자·출처·실제 적용 조건을 표시하고 평창군의 실제 장소 검색으로 연결되는 흐름을 확인했다.
- 인제군·설악산 사진 검색에서 10장의 이미지 로드를 확인했다. 사진 화면은 320·375·768·1280px에서 가로 넘침 없이 한 열·두 열·세 열로 배치됐다.
- 춘천시 지정 검색과 춘천향교 선택·실제 상세·원본 이야기·음성 컨트롤 표시를 확인했다.
- 춘천향교 상세의 연관 자료에서 케이블카를 후보에 추가했을 때 기존 선택이 유지됨을 확인했다. 두 장소를 직접 담아 실제 코스를 생성하고 케이블카를 먼저 방문하도록 바꿔 저장했다. 새로고침 후 실제 장소를 재조회해 같은 순서로 복원했고 지도 마커 두 개를 확인했다.
- 복원한 코스 화면은 320·375·768·1280px에서 가로 넘침이 없었다. 모바일 화면의 방문 순서·주소·상세·길찾기 배치를 확인했다.
- 기존 기본 흐름의 세 곳 제한·네 번째 선택 차단·지정 장소 교체·ESC 닫기·실제 코스 재조회·지도 마커·순서 변경·저장 복원은 앞선 화면 검증에서 확인했다.

## 미확인 항목과 범위

오디의 실제 음성 파일 응답과 컨트롤 표시를 확인했지만 재생 완료는 확인하지 못했다. 인앱 브라우저에서 재생을 시도하던 중 페이지가 종료됐다. 일반 브라우저 재생 확인은 별도로 남아 있다. 원본 음성 파일 열기와 대본 읽기를 대안으로 제공한다.

OpenAI의 서버 인증키·모델은 아직 함께 설정되지 않았다. 모의 응답으로 구조화 요청·nullable 시군·서버 검증·소개 원문 대조를 확인했으며 실제 계정·모델 호출은 미검증이다. 현재는 자동 해석 실패 안내와 직접 조건 선택·확인된 사실로 진행한다. 실제 연결 준비와 평가 사례는 [AI 연결 안내](AI_SETUP_AND_CHECK.md)를 따른다.

공개 운영 주소 배포·공모전 제출·서버 저장·공유·사진 인식 모델·주변 반경 검색·도보·대중교통 경로·실시간 위치 추적·최적 순서·체류 시간 기반 일정 검증·날씨·혼잡 기능은 완료 범위에 포함하지 않는다. 자동차 예상 이동 조회는 위의 검증 범위를 따른다. 연관 자료는 2025년 4월의 참고 자료이며 실시간 인기나 최단 경로가 아니다.

## 실행과 재확인

일반 실행은 README의 프런트 3000·백엔드 8000 구성을 따른다. 이번 화면 검증은 실행 중인 3000 프런트와 8000 백엔드를 사용했다. 운영 미리보기는 `.next-preview` 산출물 폴더를 사용할 수 있다. 운영 빌드에 API 연결 주소가 반영되므로 주소가 바뀌면 다시 빌드한다.

프로젝트 루트에서:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools/check_live_tourism.py
.\.venv\Scripts\python.exe tools/check_extra_tourism.py
.\.venv\Scripts\python.exe tools/export_day_trip_contract.py
```

`web`에서:

```powershell
npm run typecheck
npm run lint
npm test
npm run build
```

외부 조회 명령은 실제 관광 API 호출량을 사용한다. 모의 테스트는 실제 외부 연결이나 공개 운영 배포를 증명하지 않는다.
