| 항목 | 결과 | 범위 |
|---|---|---|

| 문서 점검 | 통과 | 현재 문서의 일본어·중국어 없음, 내부 링크 오류 없음 |
| 비밀 값 점검 | 통과 | 현재 공개 소스·문서에 서버 관광 인증키 없음 |

검증은 잘못된 ID·중복·빈 선택·세 곳 초과, 지역·유형·존재 여부, 잘못된 좌표·이미지·HTML, 외부 조회 실패를 포함한다. 최종 AI 근거 요청은 여러 장소를 한 번에 보내며 소개 원문에 없는 구절은 채택하지 않는다.

지역 검증은 강원도 전체 검색에서 시군 코드 생략, 선택한 시군의 실제 주소 대조, 잘못된 시군의 외부 호출 전 거절을 포함한다. 서로 다른 국문·연관 서비스 코드를 혼용하지 않는지 검사한다. 연관 후보는 전체 이름을 정규화한 단일 장소만 연결하고, 동명 장소가 둘이면 연결하지 않는다. 띄어쓰기 보조 검색에서도 이 조건을 유지한다.

사진은 촬영지·이미지 주소를 검증하며 관광 장소 ID나 정확한 좌표를 만들어내지 않는다. 오디는 관광지명·언어·제공 위치를 대조하고 원문을 정리한다. 추가 관광 서비스가 실패해도 기본 장소 상세 조회가 유지되는지 검사했다. 먼 코스의 안내는 직선거리이며 이동시간을 창작하지 않는다.

추가 자료의 검색 결과 없음과 검색 결과는 있지만 대조 조건 불일치로 채택되지 않은 경우를 이야기·연관 각각에서 검사했다. 네 사례 모두 HTTP 200과 빈 목록·원인 안내를 반환하며 기본 장소 소개는 유지된다.

무장애 정보는 동일 ID라도 이름·주소·유형·제공 위치가 다른 자료의 연결을 거절한다. 이름 검색 때 별도 지역코드를 사용하고 다른 서비스 ID로 동일 장소를 확인한 경우만 세부 자료를 연결한다. 동명 ID의 중복, 다른 ID의 세부 응답, 빈 항목, HTML 원문 정리, 잘못된 입력, 추가 조회 실패 시 기본 상세 유지도 모의 검증했다.

## 실제 외부 연결

| 항목 | 확인한 결과 |
|---|---|
| 국문 지역 목록 | 강원특별자치도 코드 32·18개 시군 |
| 강원도 전체 검색 | 후보 18개, 강릉·고성·동해·삼척·양양 등 여러 시군 |
| 춘천 검색 | 춘천시의 실제 관광 후보 조회·주소 검증 |
| 관광사진 | 강원 키워드의 촬영지 검증 사진 12장, 평창·인제 예시 확인 |
| 오디 | 춘천향교 12_125780과 관광지명·좌표가 일치하는 한국어 원본 이야기 1개 |
| 오디 음성 파일 | HTTPS 파일의 HTTP 206·audio/mpeg·일부 본문 수신 확인 |
| 연관 관광지 | 기준월 202504·강원 51·춘천 51110, 춘천향교의 연관 후보 5개 |
| 실제 장소 연결 | 춘천 삼악산 호수케이블카 12_2814588의 국문 이름·지역 확인 |
| 무장애 여행정보 | 가원습지 생태자연공원 12_2714889의 접근로·출입구·보조견 동반 세 항목, 강릉 복사꽃마을 12_128359의 대중교통 한 항목 |
| 무장애 자료 누락 | 춘천향교 12_125780 조회 완료·동일 장소 미확인·편의 항목 0개 |
| 프런트 내부 연결 | 상태·지역·이야기·연관 API의 HTTP 200 확인 |

이전 최소 확인에서 사진 검색 전체 9,607건, 춘천 오디 14건, 춘천 연관 1,321건의 응답 수를 확인했다. 이 수치는 요청 조건의 검색 건수이며 고유 관광 장소 수나 연결 성공 수가 아니다. 일부 관광사진의 제공 주소는 로드되지 않아 사진 누락 안내를 표시한다.

추가 자료 누락 점검에서 계방산(평창)·강원수산횟집·2018 평창동계올림픽대회 및 동계패럴림픽대회 기념관의 이야기·연관 조회는 모두 HTTP 200·연결 자료 0개였다. 계방산 오디 이름 검색은 0건, 연관 이름 검색은 중심 관광지명이 계방산오토캠핑장인 3건이어서 계방산 자료로 채택하지 않았다. 평창 지역 오디에는 별도 장소의 자료가 있고, 연관 API의 올림픽 검색에는 평창올림픽기념관이라는 이름이 나타났다. 공식 이름과 별칭의 동일 장소 검증이 없는 자료는 임의로 연결하지 않는다. 비교용 춘천향교는 이야기 1개·연관 후보 5개·국문 연결 장소 1개를 다시 확인했다.

실제 관광 API는 사용자 설정으로 호출했다. 실제 인증키·인증 URL은 출력하지 않았다. 국문 서비스의 기존 인증 설정은 유지하고 별도 세 서비스의 설정을 서버에서 읽는다.

## 화면 확인

- 가원습지 상세의 ‘방문 편의정보’에서 접근로·출입구·보조견 동반 항목과 출처·장소 자료 수정일을 확인했다. 375px 모바일에서 네 상세 버튼이 두 줄로 배치되고 가로 넘침 없이 표시됐다. 춘천향교의 편의자료 없음 안내와 장소 소개 복귀도 확인했다.
- 계방산 상세에서 이야기 검색 결과 없음과 연관 대조 조건 불일치 안내가 각각 표시되는 것을 확인했다. 두 영역의 조회 완료·자료 없음 표시와 장소 소개로 돌아가는 버튼이 동작했다.
- 장소 카드·상세 화면·관광사진 목록은 원본 비율을 유지하는 `object-fit: contain`으로 사진 전체를 표시한다. 프레임과 사진의 비율이 다르면 남는 공간에 연한 배경을 표시한다. 평창군의 실제 계방산·음식점·올림픽 기념관 사진에서 잘림 없이 표시되는 것을 확인했다.
- 사진 탐색에 촬영지·촬영자·출처·실제 적용 조건을 표시하고 평창군의 실제 장소 검색으로 연결되는 흐름을 확인했다.
- 인제군·설악산 사진 검색에서 10장의 이미지 로드를 확인했다. 사진 화면은 320·375·768·1280px에서 가로 넘침 없이 한 열·두 열·세 열로 배치됐다.
- 춘천시 지정 검색과 춘천향교 선택·실제 상세·원본 이야기·음성 컨트롤 표시를 확인했다.
- 춘천향교 상세의 연관 자료에서 케이블카를 후보에 추가했을 때 기존 선택이 유지됨을 확인했다. 두 장소를 직접 담아 실제 코스를 생성하고 케이블카를 먼저 방문하도록 바꿔 저장했다. 새로고침 후 실제 장소를 재조회해 같은 순서로 복원했고 지도 마커 두 개를 확인했다.
- 복원한 코스 화면은 320·375·768·1280px에서 가로 넘침이 없었다. 모바일 화면의 방문 순서·주소·상세·길찾기 배치를 확인했다.
- 기존 기본 흐름의 세 곳 제한·네 번째 선택 차단·지정 장소 교체·ESC 닫기·실제 코스 재조회·지도 마커·순서 변경·저장 복원은 앞선 화면 검증에서 확인했다.

## 미확인 항목과 범위

오디의 실제 음성 파일 응답과 컨트롤 표시를 확인했지만 재생 완료는 확인하지 못했다. 인앱 브라우저에서 재생을 시도하던 중 페이지가 종료됐다. 일반 브라우저 재생 확인은 별도로 남아 있다. 원본 음성 파일 열기와 대본 읽기를 대안으로 제공한다.

OpenAI의 서버 인증키·모델은 아직 함께 설정되지 않았다. 모의 응답으로 구조화 요청·nullable 시군·서버 검증·소개 원문 대조를 확인했으며 실제 계정·모델 호출은 미검증이다. 현재는 자동 해석 실패 안내와 직접 조건 선택·확인된 사실로 진행한다. 실제 연결 준비와 평가 사례는 [AI 연결 안내](AI_SETUP_AND_CHECK.md)를 따른다.

공개 운영 주소 배포·공모전 제출·서버 저장·공유·사진 인식 모델·주변 반경 검색·실제 교통 경로·이동시간·날씨·혼잡 기능은 완료 범위에 포함하지 않는다. 연관 자료는 2025년 4월의 참고 자료이며 실시간 인기나 최단 경로가 아니다.

## 실행과 재확인

로컬 미리보기는 http://127.0.0.1:3007이며 FastAPI의 8017 포트에 연결한다. 일반 실행은 README의 프런트 3000·백엔드 8000 구성을 따른다. 운영 빌드에 API 연결 주소가 반영되므로 주소가 바뀌면 다시 빌드한다.

프로젝트 루트에서:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools/check_live_tourism.py
.\.venv\Scripts\python.exe tools/check_extra_tourism.py
.\.venv\Scripts\python.exe tools/export_day_trip_contract.py
```

`web`에서:

```powershell
npm run typecheck
npm run lint
npm test
npm run build
```

외부 조회 명령은 실제 관광 API 호출량을 사용한다. 모의 테스트는 실제 외부 연결이나 공개 운영 배포를 증명하지 않는다.
