# 개인정보 운영 점검

2026년 10월 17일 문서 점검 기준. 운영 설정은 아래에 적은 과거 확인 범위이며 이번에 콘솔을 재점검한 것은 아니다. 코드 수정과 운영 설정 확인을 구분한다. 이 문서는 법률 적합성 인증이 아니며, 공개한 방침을 실제 설정과 맞추기 위한 작업 기록이다.

## 반영한 처리 경계

- 가입 시 약관·방침 버전과 확인 시각, 만 14세 이상 자기 확인을 기록한다. 생년월일·신분증은 받지 않는다. 닉네임은 선택이며 거절해도 계정 저장을 제공한다.
- 기존 사용자가 다시 로그인할 때 닉네임 표시를 선택하지 않으면 서버의 이전 선택 닉네임도 비우고 화면에는 ‘여행자’를 표시한다. 계정 식별값과 저장 코스는 유지한다.
- AI 사용은 기본 false다. 문장·키워드·선호 조건·공식 소개의 OpenAI 전송을 별도로 안내하고 선택한 최신 버전에서만 호출한다. 거절 시 기본 문장 조건 정리·지도·사진 검색·사실 기반 코스는 유지한다.
- AI 선택은 저장 코스에 넣지 않으며 복원 요청은 항상 false다. 계정 ID·토큰·방문·메모를 AI에 넣지 않는다. 원문을 DB에 저장하지 않는다는 설명과 외부 보관이 없다는 설명은 다르다.
- 만료·폐기 세션을 서버 시작·실행 중 매시간 정리한다. 잠든 서버나 DB 장애에서는 다음 실행에 정리가 지연될 수 있다. 탈퇴는 운영 DB의 사용자와 관련 행을 연쇄 삭제하고 해당 브라우저의 여행 기록도 지운다.
- 기본 Uvicorn 접근 로그에서 쿼리 문자열을 제거해 OAuth 코드·상태를 남기지 않는다. 경로·응답 상태는 유지한다. 호스팅 사업자의 자체 로그까지 제거하는 기능은 아니다. 인증 응답에는 `Referrer-Policy: no-referrer`를 적용한다.
- 개인정보 문의를 공개 GitHub 이슈로 보내던 링크를 제거했다. 일반 오류 제보에도 계정·토큰·개인정보를 올리지 않도록 한다.
- 10월 8일 사용자가 만든 `storyroute.help@gmail.com`을 비공개 개인정보 문의 주소로 등록했다. `/privacy`에 주소와 메일 링크를 표시한다. 운영자가 이후 메일 테스트를 완료했다고 알려왔다. 시험 날짜·상세 결과는 따로 기록하지 않았으며 이 문서 점검에서 재시험하지 않았다.

## 확인한 운영 위치

| 구분 | 확인 결과 | 확인 근거 |
|---|---|---|
| Vercel 서버 함수 | 미국 워싱턴 DC `iad1` | 프로젝트 Functions 설정의 선택 지역 직접 확인 |
| Render API | 미국 서부 | 운영 호스트 DNS의 `gcp-us-west1` 연결 확인 |
| Neon PostgreSQL | 싱가포르 | 운영 연결 호스트의 `ap-southeast-1` 확인. 주소·비밀번호는 기록하지 않음 |
| OpenAI | 일반 API 주소 사용, 미국 전송 안내 | 지역별 데이터 보관 계약·ZDR를 설정했다고 가정하지 않음 |

Vercel CDN과 제공처 자체 보안·지원 처리는 위 서버 함수 위치와 동일하다고 단정하지 않는다. OpenStreetMap 타일 요청은 브라우저에서 직접 이루어지는 외부 접속이며 이를 방침에 안내한다.

## 아직 운영자가 완료해야 하는 항목

1. **문의 대응 절차:** 운영자 보고로 메일 테스트는 완료했다. 실제 문의의 본인 확인·답변·삭제 처리 절차는 별도로 정리하고, 비밀번호·인증 토큰·신분증을 불필요하게 요구하지 않는다.
2. **Neon 복구본 보관기간:** 실제 콘솔 설정을 확인하지 못했다. 요금제 기본값이나 예전 문서를 현재 값으로 추정하지 않는다. 프로젝트의 restore window·별도 스냅샷/브랜치·내보낸 백업 여부를 확인하고 방침에 실제 기간을 기재한다. 사용자를 삭제한 후 과거 복구본을 복원하면 삭제한 정보가 재등장할 수 있으므로 복원 전 삭제 요청의 재적용 절차도 마련한다.
3. **제공처 계약·연락처:** Vercel·Render·Neon 처리위탁/DPA와 하위처리자·국외 처리 조건을 실제 사용 계정 기준으로 점검한다. AI 선택 수신 기록은 요청별 플래그 검증이며 별도의 장기 동의 증빙 DB를 만들지는 않았다. 이를 법적 동의 증빙의 완성으로 표현하지 않는다.
4. **실제 카카오의 남은 경로:** 기존 계정의 별도 브라우저 로그인·코스 복원, 로그아웃, 탈퇴, 같은 카카오의 새 계정 재로그인과 빈 코스 목록은 운영에서 확인했다. 처음 사용하는 카카오 계정의 최초 가입, 닉네임 표시 선택 경로, 다른 물리적 기기는 아직 별도 확인이 필요하다.

10월 2일 공개 `/privacy`에서는 문의 이메일이 ‘준비 중’, DB 복구본 보관기간이 ‘확인 중’으로 표시됐다. 10월 8일 문의 주소를 코드에 반영하고, 10월 9일 공개 배포에서 이메일과 `mailto:` 링크가 표시되는 것을 확인했다. Neon 콘솔은 로그인이 필요해 이 프로젝트의 실제 복구 기간과 별도 백업 여부를 확인하지 못했다. 기존 계정의 코스 재열기·로그아웃, 10월 3일 별도 브라우저에서의 코스 복원·새로고침 후 로그인 유지·탈퇴·같은 카카오 재로그인 후 빈 코스 목록은 [운영 검증 기록](./VALIDATION.md)에서 확인할 수 있다. 탈퇴는 운영 DB의 행 삭제 건수나 제공처 복구본 삭제를 직접 확인한 것은 아니다.

제공처의 공개 계약 자료는 [Vercel DPA](https://vercel.com/legal/dpa), [Render DPA](https://render.com/dpa), [Neon DPA](https://neon.com/pdf/DPA.pdf)에서 확인할 수 있다. 공개 문서의 존재가 현재 계정에 적용·체결됐다는 증거는 아니다. 실제 요금제와 계정에 적용되는 최신 계약 조건을 별도로 확인한다.

추가 검증에서는 처음 사용하는 카카오 계정으로 최초 가입과 닉네임 표시 선택 경로를 확인하고, 다른 물리적 기기에서 계정 코스가 열리는지 확인한다. 방문 체크·장소 메모는 현재 기기 기록이므로 기기 간 복원 대상으로 계산하지 않는다. 새 계정에 코스를 저장하지 않았으므로 신규 계정에서의 저장·복원은 이번 운영 확인 범위에 포함하지 않는다.

## 반영 이력과 이후 변경 방법

`20260930_01` 마이그레이션은 2026년 9월 30일 로컬과 운영 DB에 적용하고 새 NULL 허용 컬럼의 존재를 확인했다. 기존 사용자·코스를 지우거나 과거 확인을 추정해 채우지 않았다. 이 작업을 아직 해야 하는 배포 단계로 안내하지 않는다.

이후 개인정보 확인 항목이나 코드를 변경할 때는 적용 대상 DB의 `alembic current`와 백업·복구 가능 여부를 먼저 확인한다. 새 확인을 요구하는 화면과 서버는 같은 버전으로 배포하고, 이전 브라우저가 필수 확인 없이 요청하면 최신 화면으로 다시 진행하도록 안내한다. 공개 문의 주소는 `web/lib/privacy-contact.ts`에 있으므로 바꾸면 재배포 후 `/privacy`의 이메일·링크를 확인한다. 비밀키는 코드에 넣지 않는다.

## 공식 확인 자료

- [개인정보 보호법 국외 이전 안내 항목](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029332501)
- [OpenAI API 데이터 보관](https://developers.openai.com/api/docs/guides/your-data): `store:false`는 별도 보안 로그 제거 또는 ZDR를 의미하지 않는다. 실제 계정과 모델에 적용되는 보관 조건을 확인한다.
- [Vercel 런타임 로그](https://vercel.com/docs/logs/runtime): 실제 요금제의 런타임 로그 보관 범위를 확인한다.
- [Render 로그 보관](https://render.com/docs/logging): 실제 요금제의 로그 보관 기간을 확인한다. 별도 배포·지원 기록까지 같은 기간이라고 단정하지 않는다.
- [카카오 사용자 정보 조회 범위](https://developers.kakao.com/docs/ko/kakaologin/rest-api)

문의 대응 절차, 복구본 보관기간, 제공처 조건 확인이 남아 있으므로 이번 수정만으로 개인정보 관련 의무가 모두 완료되었다고 표현하지 않는다.
