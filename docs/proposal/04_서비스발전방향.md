# 4) 서비스 발전 방향

2026년 9월 20일 개정 · 향후 계획

## 1. 단기

강원도 하루 코스의 입력·수정·검색·선택·교체·지도·저장·복원 흐름을 안정화한다. 실패·누락 상태와 모바일 접근성을 확인하고 실제 사용 사례를 수집한다.

## 2. 중기

로그인·계정 코스 저장 다음 단계로 공개 범위를 선택하는 공유 링크와 방문 기록의 계정 동기화를 검토한다. 기준 장소 주변 반경 검색과 관광 콘텐츠의 연결 정확도도 개선한다. 방문 사진과 공개 리뷰는 이미지 저장소·신고·삭제 정책을 먼저 마련한 뒤 여행 전 코스가 여행 후 개인 지도와 기록으로 이어지도록 확장한다.

이미지 인식은 사진 업로드·기록 흐름 이후 관찰 가능한 이미지 태그 제안으로 도입하고 오류를 사용자 수정으로 처리한다. TensorFlow 등 모델 기술은 해당 기능과 평가 목적에 맞춰 선택한다. 키워드 검색의 한계를 확인하면 의미 검색의 개선 효과를 비교한다.

## 3. 기대효과

여행 조건 해석과 장소 선택을 한 흐름에 묶어 짧은 여행 계획의 반복 작업을 줄이는 것을 목표로 한다. 실제 계획 완료율·조건 수정 사례·실패 대응·검색부터 저장까지의 시간을 측정해 효과를 확인한다. 자체 모델 학습·교통 최적화·날씨·혼잡 예측은 구현과 검증 전 성과로 주장하지 않는다.
