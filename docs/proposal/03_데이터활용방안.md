# 3) 데이터 활용 방안

2026년 9월 20일 개정 · 실제 구현과 연결 확인 범위를 기준으로 작성

## 1. 한국관광공사 관광 API

| 데이터 | 용도 |
|---|---|
| 지역·시군구 코드 | 실제 응답에서 강원과 선택 시군 검색 범위 결정 |
| 지역기반 관광 목록 | 관심 유형별 강원도 후보 조회 |
| 키워드 관광 검색 | 여행 문장에서 해석한 키워드의 후보 보조 조회 |
| 공통·소개 상세 정보 | 장소 존재·주소·분류·소개·좌표와 유형별 운영시간·휴무일·주차 등 재확인 |

현재 어댑터는 국문 관광정보 서비스 KorService2를 중심으로 관광사진·오디오 가이드·기준월 연관 관광지·무장애 여행정보를 연결한다. 혼잡·날씨 API를 연결한 것으로 표현하지 않는다.

## 2. 활용 방식

FastAPI가 서버 설정의 인증키로 외부 관광 API를 호출하고 내부 화면용 필드로 정리한다. 프런트는 내부 API만 요청한다. 장소의 사진·좌표가 누락되면 누락 안내를 표시한다.

최종 코스를 만들 때 장소를 다시 조회하고, AI가 반환한 장소 ID와 단서 구절을 실제 소개 원문과 대조한다. AI 실패 때도 확인된 관광 정보는 제공한다.

비회원 브라우저에는 선택 ID·순서·조건·저장 시각과 직접 방문 기록을 저장한다. 로그인 사용자는 계정 코스의 제목·ID 순서·조건을 PostgreSQL에도 저장한다. 운영시간·소개·사진 같은 관광 원천 데이터는 대량 영속 저장하지 않고 코스를 열 때 다시 조회한다. 실제 콘텐츠에 ‘출처: ⓒ한국관광공사’를 표시한다.

실제 연결과 모의 AI 검증 결과는 [검증 기록](../VALIDATION.md)에 구분해 적는다.

## 별도 관광 콘텐츠

관광사진은 촬영지에서 강원도를 확인하고 지역 검색으로 연결한다. 오디 원본 이야기·음성은 관광지명과 제공 좌표를 대조해 상세에서 조회한다. 연관 관광지는 별도 공식 코드와 기준월을 사용하고 국문 관광정보에서 이름·지역이 확인된 단일 장소만 후보로 연결한다. 자료 기준월과 없는 콘텐츠를 명시하며 현재 인기·이동시간을 임의로 만들지 않는다.
