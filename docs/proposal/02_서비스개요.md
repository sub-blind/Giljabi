# 2) 서비스 개요

2026년 9월 20일 개정 · 제출 양식에 옮기기 전의 기획 초안

## 1. 기획 서비스 소개

원하는 여행을 말하고 실제 관광 장소를 골라 나만의 강원도 하루 코스를 만드는 반응형 웹 서비스.

## 2. 주요 기능

| 기능 | 사용자 경험 |
|---|---|
| 지도·문장·사진 탐색 | 강원도 18개 시군 지도, 여행 문장 해석, 관광사진의 촬영지역에서 시작 |
| 실제 장소 검색·상세 | 관광 공공데이터의 사진·주소·소개와 전화·운영시간·휴무일·주차 등 제공 정보 확인 |
| 장소 선택·교체 | 최대 세 장소를 담고 특정 장소를 현재 후보의 다른 장소로 교체 |
| 하루 코스·여행 | 장소 재검증, 방문 순서 변경, 다음 장소·이야기·편의정보·방문 기록 연결 |
| 지도·저장 | 실제 좌표·카카오 자동차 이동·카카오맵 길찾기, 비회원 브라우저 저장과 로그인 계정 코스 저장 |

## 3. 서비스 차별성

조건 해석을 사용자가 고치고, 추천된 장소를 카드에서 직접 선택·교체하며, 관광 데이터로 확인한 사실과 AI가 선택한 원문 단서를 구분하는 흐름에 집중한다. 직접 지도 검색은 지역·유형만 받아 빠르게 시작하고 세밀한 취향은 문장 검색에서 해석한다. 확인할 수 없는 날씨·혼잡·접근성 등은 충족을 보장하지 않는다.

## 4. 제공 지역

첫 버전은 강원도 당일 여행이다. 관광 API에서 강원·선택 시군 지역코드를 조회하고 실제 주소·유형·ID를 검사한다. 이 제한은 개발 범위이며 공모전의 지역 특화 인정 여부나 가산점을 자동 보장하는 것으로 표현하지 않는다.

공식 제출 자격·양식·지역 특화 요건은 최신 공고와 실제 기능을 기준으로 확인한다.
