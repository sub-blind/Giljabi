# 2) 서비스 개요

2026년 9월 17일 개정 · 제출 양식에 옮기기 전의 기획 초안

## 1. 기획 서비스 소개

원하는 여행을 말하고 실제 관광 장소를 골라 나만의 강원도 하루 코스를 만드는 반응형 웹 서비스.

## 2. 주요 기능

| 기능 | 사용자 경험 |
|---|---|
| 조건 해석·수정 | 여행 문장을 해석하거나 직접 관심 유형·키워드를 선택 |
| 실제 장소 검색·상세 | 관광 공공데이터의 사진·주소·분류·소개·근거 확인 |
| 장소 선택·교체 | 최대 세 장소를 담고 특정 장소를 현재 후보의 다른 장소로 교체 |
| 하루 코스 | 장소 재검증, 원문과 대조한 AI 단서 또는 실제 사실, 방문 순서 변경 |
| 지도·저장 | 실제 좌표 마커·외부 길찾기·브라우저 저장과 재조회 복원 |

## 3. 서비스 차별성

조건 해석을 사용자가 고치고, 추천된 장소를 카드에서 직접 선택·교체하며, 관광 데이터로 확인한 사실과 AI가 선택한 원문 단서를 구분하는 흐름에 집중한다. 키워드 선호와 확인할 수 없는 날씨·혼잡·접근성 등은 충족을 보장하지 않는다.

## 4. 제공 지역

첫 버전은 강원도 당일 여행이다. 관광 API에서 강원·선택 시군 지역코드를 조회하고 실제 주소·유형·ID를 검사한다. 이 제한은 개발 범위이며 공모전의 지역 특화 인정 여부나 가산점을 자동 보장하는 것으로 표현하지 않는다.

공식 제출 자격·양식·지역 특화 요건은 최신 공고와 실제 기능을 기준으로 확인한다.
