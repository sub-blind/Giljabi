# 강원도 기준 관광 API 선정안

2026년 9월 17일 · 한국관광콘텐츠랩 OpenAPI 목록 26개 검토

## 지역 기준과 구현 상태

사용자가 정정한 서비스 대상은 **강원특별자치도 전체**다. 강릉은 강원도 안의 선택 가능한 지역 중 하나다. 이 기준이 이전 기획의 강릉 고정 범위보다 우선한다.

현재 프런트·백엔드·API 계약은 강원도 전체와 18개 시군 선택을 지원한다. 관광사진 탐색, 오디 원본 이야기와 기준월 연관 자료도 화면에 연결했다. 기존 v1 강릉 저장은 v2의 강원도·강릉시 조건으로 읽고 실제 장소를 재검증한다.

국문 관광정보의 `areaCode2`를 실제 호출해 강원특별자치도 지역코드 `32`와 18개 시군을 확인했다. 이 코드는 해당 서비스의 코드이며 다른 API의 지역코드와 같다고 가정하지 않는다. 서비스에서는 코드 목록을 조회해 지역 선택지를 구성한다.

## 선정 결과

| 우선순위 | API | 서비스에서 사용할 기능 | 첫 버전 판단 |
|---|---|---|---|
| 1 | 국문 관광정보 서비스 | 강원도·시군 검색, 주변 장소, 소개·방문 정보, 장소 사진, 행사 | 필수 |
| 2 | 관광사진 정보 | 사진 제목·촬영지·키워드를 이용한 강원도 사진 카드와 여행 분위기 탐색 | 구현: 촬영지 확인 후 시군 검색 연결 |
| 3 | 관광지 오디오 가이드정보 | 관광지의 실제 역사·문화 대본을 활용한 이야기 카드, 원본 오디오 | 구현: 이름·제공 위치 대조 후 원본 제공 |
| 4 | 관광지별 연관 관광지 정보 | 기준 관광지와 연결성이 높은 다음 장소를 추천하는 보조 자료 | 구현: 기준월 표시·국문 장소 대조 후 후보 연결 |
| 5 | 무장애 여행정보 | 방문 편의시설의 제공 항목 확인 | 구현: 동일 장소 확인 후 상세에서 필요할 때 조회 |

첫 버전은 국문 관광정보로 완주할 수 있게 한다. 사진 API나 AI 연결 실패 때문에 장소 검색·선택·코스 확인이 막히지 않게 구성한다.

## 국문 관광정보: 실제 장소와 코스의 기반

- `areaCode2`: 강원도와 시군 선택지를 조회한다.
- `areaBasedList2`: 강원도 전체 또는 선택한 시군의 장소 후보를 조회한다.
- `searchKeyword2`: 해변·숲·전시·카페 등 관심 키워드를 검색한다.
- `locationBasedList2`: 사용자가 선택한 장소 좌표를 기준으로 다음 장소 후보를 찾는다.
- `detailCommon2`: 이름·주소·분류·좌표·공식 소개를 확인한다.
- `detailIntro2`: 장소 유형에 맞는 이용시간·휴무일·주차 등 제공 정보를 확인한다.
- `detailImage2`: 추가 장소 사진을 제공할 때 사용하며, 빈 응답·형식 차이를 먼저 처리한다.
- `searchFestival2`: 여행 날짜를 지원할 때 강원도 행사 후보를 추가한다. 날짜 입력과 행사 유형의 계약 변경이 함께 필요하다.

강원도 전체에서 여행지를 발견할 수 있게 하되, 당일 코스는 시군 또는 기준 장소 주변에서 구성하도록 안내한다. 거리가 먼 장소가 함께 선택되면 사용자에게 알린다. 위치기반 반경과 직선거리는 실제 자동차 이동시간이나 도보 가능 경로를 의미하지 않는다.

소개정보의 값이 비어 있으면 ‘정보 없음’으로 표시한다. 이용시간이 없는 장소를 상시 이용 가능한 것으로 해석하거나, 주차 정보만으로 접근성·여행일의 이용 가능 여부를 보장하지 않는다.

## 관광사진: 사진을 보며 여행을 시작하는 흐름

공식 명세의 `PhotoGalleryService1/gallerySearchList1`은 키워드로 사진을 검색한다. 응답에는 `galContentId`, `galTitle`, `galWebImageUrl`, `galPhotographyLocation`, `galPhotographer`, `galSearchKeyword` 등이 있다.

이 데이터를 활용한 제안 흐름은 다음과 같다.

1. 강원도 여행 사진을 보고 마음에 드는 장면을 고른다.
2. 촬영지·키워드를 확인하고 원하는 지역·관심을 직접 수정한다.
3. 국문 관광정보에서 실제 장소를 찾아 후보로 제시한다.
4. 사용자가 장소를 선택하고 주변 장소를 더해 하루 코스를 만든다.

사진 검색 명세에 관광 장소의 `contentid`나 좌표가 공통 필드로 제공되는 것은 확인되지 않았다. 사진 ID를 관광 장소 ID로 쓰지 않는다. 촬영지·키워드로 실제 장소를 연결하고, 확실한 연결이 없으면 사진을 정확한 지도 위치에 고정하지 않는다. 키워드 검색 결과도 촬영지 정보를 대조해 강원도 범위인지 확인한다.

사진 API 자체가 이미지 인식을 수행하는 것은 아니다. 후속 이미지 AI에서는 바다·숲·건물처럼 관찰 가능한 태그를 제안하고 사용자가 수정하도록 한다. 사진만으로 정확한 장소, 혼잡, 영업 여부를 단정하지 않는다. 출처·촬영자 정보를 함께 표시하고 이미지 활용 조건을 따른다.

## 오디오 가이드: 확인된 이야기를 덧붙이는 확장

공식 설명은 오디의 음성·대본·사진과 관광지·이야기의 위치기반 및 키워드 검색 정보를 제공한다고 안내한다. 현재 관광지명·제공 위치를 대조한 콘텐츠를 상세에서 원본 대본·오디오로 제공한다. 모든 장소에 이야기가 있는 것은 아니다.

콘텐츠가 있는 장소에 짧은 이야기 카드와 원본 오디오를 붙일 수 있다. LLM을 쓰면 제공된 대본을 바탕으로 출처가 있는 요약을 만들고, 기록되지 않은 전설·역사를 새로 만들지 않게 검증한다. 모든 강원도 장소에 이야기가 있는 것으로 표현하지 않는다.

## 연관 관광지: 데이터의 기간과 코드부터 확인

공식 설명에 따르면 티맵 내비게이션 데이터의 차량 이동 조건을 기반으로 산출한 연결성 정보다. 실제 연계 방문자 수나 최단 경로를 그대로 나타내는 지표로 해석하지 않는다.

검토한 명세는 `TarRlteTarService1/areaBasedList1`, `searchKeyword1`이며, 기준월 `baseYm`과 별도 지역·시군 코드를 입력한다. 응답의 `tAtsCd`, `rlteTatsCd`는 국문 관광정보의 `contentid`와 동일하다고 가정하지 않는다.

검토 시점의 공식 설명은 2024년 5월부터 2025년 4월까지의 데이터를 안내했다. 현재 인기나 실시간 추천으로 표시하기 전에 실제 지원 기준월과 갱신 상태를 확인한다. 현재는 기준월 `202504`의 연관 자료를 보조 후보로 사용한다. 주변 반경 검색·실시간 추천은 현재 화면에 구현되지 않았다.

## 실제 확인한 내용

### 무장애 여행정보 확장

사용자가 제공한 `KorWithService2` 엔드포인트와 인증을 서버 전용 설정으로 추가했다. 해당 서비스의 `areaCode2`를 호출해 강원 코드 32를 확인하고, 강원 관광지 유형의 `areaBasedList2` 조회에서 167건 중 예시 세 장소를 확인했다. 전체 수록 범위나 고유 장소 수가 아니라 이 요청의 검색 건수다.

가원습지 생태자연공원과 강릉 복사꽃마을의 공통정보를 국문 장소와 관광지명·주소·제공 좌표로 대조한 뒤 `detailWithTour2`의 실제 응답을 확인했다. 전자는 접근로·출입구·보조견 동반의 세 항목, 후자는 대중교통 한 항목을 내부 API로 연결했다. 춘천향교는 동일 장소를 확인한 자료가 없어 빈 결과를 안내한다.

ID가 같다고 무조건 결합하지 않는다. 공통정보에서 대조가 안 되면 무장애 서비스 자체 지역코드와 이름 검색으로 후보를 찾고, 단일 장소만 연결한다. 빈 값을 불가로 추정하거나 시설 운영·여행 가능 여부를 AI로 판정하지 않는다. 현 버전에는 편의시설 조건 필터를 넣지 않는다.

| 확인 | 결과 |
|---|---|
| 국문 관광정보 지역코드 | 강원특별자치도 `32`, 18개 시군 조회 성공 |
| 기존 국문 장소 검색·상세 | 강릉 예시 장소의 이름·주소·좌표·소개 확인 |
| 국문 위치기반 검색 | 강문달카페 좌표의 반경 3km 음식점 전체 100건 중 5건 조회 |
| 국문 소개정보 | 도직해변 주차 ‘가능’, 문의 안내 확인. 이용시간·휴무일은 값 없음 |
| 관광사진 별도 API | 기존 서버 키는 HTTP 403. 이후 사용자가 제공한 관광사진 인증키로 HTTP 200과 정상 결과 코드 확인. `강원` 키워드 검색 결과 9,607건 중 3건 조회; 평창군 진부면 국립조선왕조실록박물관 사진 정보 확인 |
| 국문 추가 이미지 조회 | 해당 도직해변 요청에서 본문 정보를 확인하지 못함. 정상 사진 목록 처리 미검증 |
| 오디오 가이드 API | 서버에 저장한 인증으로 HTTP 200·정상 코드 확인. `춘천` 국문 이야기 검색 14건 중 3건 조회. 춘천향교·국립춘천박물관·춘천과 소양강 이야기에서 대본·음성 URL 존재 확인. 이후 춘천향교 국문 장소 `12_125780`과 이름·좌표를 대조해 원본 이야기 연결. 음성 파일 HTTP 206·audio/mpeg 확인 |
| 연관 관광지 API | 서버에 저장한 인증으로 HTTP 200·정상 코드 확인. 기준월 `202504`, 지역 `51`, 춘천 `51110`으로 연관 데이터 1,321건 중 3건 조회. 이후 춘천향교 기준 연관 자료에서 춘천 삼악산 호수케이블카 `12_2814588`을 국문 이름·지역 대조로 연결 |

실제 인증키·인증 URL을 문서나 로그에 남기지 않는다. 목록에 있는 서비스라고 현재 키로 모두 호출할 수 있다고 가정하지 않는다. 이 검토에서 별도 활용 신청이나 권한 변경은 하지 않았다.

사진·오디오·연관 서비스의 주소와 사용자 제공 인증키를 실제 Tourism 서버 `.env`에 각각 분리해 설정했다. 기존 국문 관광정보 인증키는 유지했다. `app/config.py`와 비밀 값이 없는 `.env.example`에도 설정 항목을 추가했다. 화면 연결까지 반영했다. 관광사진 12장의 촬영지 정보를 확인하고 지역 검색으로 연결했다. 일부 제공 이미지 주소는 로드되지 않아 사진 누락 안내를 표시한다. 검색 전체 건수는 조회 조건에 맞는 응답 수이며, 강원도 전체의 고유 관광 장소 수나 장소 간 연결 검증 완료 수가 아니다.

프로젝트 루트에서 `.\.venv\Scripts\python.exe tools/check_extra_tourism.py`를 실행하면 서버 설정으로 사진·오디오·연관 API를 최소 조회한다. 실제 호출량을 사용하며 인증키·인증 URL·대본 전체를 출력하지 않는다. 새 서버 설정은 백엔드를 다시 시작한 뒤 반영된다.

## 함께 반영한 지역 변경

- `Intent.region`을 `gangwon`, `city`를 선택 가능한 nullable 값으로 변경하고 LLM 지시문·실제 계약·프런트 타입을 함께 갱신했다.
- 국문 관광정보 코드 목록에서 강원과 18개 시군을 조회한다. 전체 검색에는 시군 코드를 보내지 않는다.
- 검색·상세·최종 코스에서 실제 주소·지역코드·선택 시군·ID·유형을 대조한다.
- 프런트의 고정 강릉 표시와 예시를 수정하고 v1 저장을 강원도·강릉시로 읽는 호환 처리를 추가했다.
- 연관 코드표는 공식 안내의 `한국관광공사_TourAPI_관광지_시군구_코드정보_v1.0.xlsx`에서 강원 지역 `51`과 18개 시군 코드를 가져왔다. 국문·연관 ID는 이름·지역 대조 없이 연결하지 않는다.
- 위치기반 반경 조회·이용시간·추가 이미지·행사는 검토한 확장 API이며 현재 프런트 흐름에 포함되지 않는다. 모의 검증과 실제 화면 결과는 [검증 기록](VALIDATION.md)을 따른다.

카카오모빌리티 자동차 길찾기를 추가했다. 관광 API는 장소 발견·근거·동일 장소 검증을 맡고, 길찾기는 장소 사이 예상 시간·거리·도로 경로를 맡는다. 서버의 기존 카카오 설정으로 실제 응답을 확인했으며 새로운 활용 신청이나 권한 변경은 하지 않았다.

국문 정보로 확인한 강원숲체험장 `12_2610850`과 가보자순대국 `39_2891703` 구간의 실제 내부 API 검증에서 HTTP 200, 거리 16,693m, 예상 1,505초, 도로 좌표 286개를 확인했다. 예상 시간은 조회 시점에 따라 바뀐다. 기본 하루 조회 상한 100회·동시 2개·10초 시간 제한·동일 구간 성공 응답 120초 재사용을 적용한다.
