# 강원도 관광 API의 역할과 데이터 연결 기준

2026년 10월 17일 코드 기준. 제공처의 현재 수록 건수·지원 기간을 새로 조사한 문서는 아니다. 실제 연동을 확인한 날짜와 사례는 [검증 기록](VALIDATION.md), 요청·응답은 [프런트·API 명세](FRONTEND_API_SPEC.md)에 둔다.

## 사용하는 서비스

| 서비스 | 사용 목적 | 연결 기준 |
|---|---|---|
| `KorService2` | 실제 장소 검색·상세·추가 사진·코스 재검증 | 장소 ID·유형·주소·지역코드 |
| `PhotoGalleryService1` | 관광사진에서 여행할 지역 발견 | 촬영지의 강원도·시군 확인. 사진 ID를 관광 장소 ID로 쓰지 않음 |
| `Odii` | 공식 원본 대본·오디오 | 한국어·정규화한 장소명·제공 좌표 대조 |
| `TarRlteTarService1` | 기준월에 연결된 관광지 탐색 | 별도 코드표·중심 장소·기준월 확인 후 국문 관광정보에 다시 대조 |
| `KorWithService2` | 방문 편의 항목 확인 | 유형·이름·주소·제공 좌표로 동일 장소 대조 |
| 카카오모빌리티 | 장소 사이 자동차 예상 시간·거리·도로 경로 | 서버가 국문 장소를 재조회한 좌표만 사용 |

국문 관광정보를 기본 장소의 기준으로 삼는다. 부가 서비스의 자료가 없거나 연결되지 않아도 기본 장소 소개와 여행 흐름을 이용할 수 있게 한다. 서비스별 키는 서버 설정으로 분리하며 프런트에 전달하지 않는다.

## 국문 관광정보와 지역 검증

현재 코드가 사용하는 국문 관광정보 호출은 다음과 같다.

- `areaCode2`: 강원도·시군 코드 조회. 과거 실제 응답의 강원 코드가 `32`였더라도 실행 중에는 목록에서 찾는다.
- `areaBasedList2`, `searchKeyword2`: 지역·유형별 결과와 키워드 결과를 조회해 중복 제거·유형별 분산 후 최대 18개 후보를 반환한다.
- `detailCommon2`: 선택한 ID의 이름·주소·유형·좌표·소개를 재확인한다.
- `detailIntro2`: 문의·운영시간·휴무일·주차·메뉴 등 유형별 제공 항목을 표시한다. 실패해도 기본 상세를 유지한다.
- `detailImage2`: 같은 장소의 추가 사진을 조회한다. 카드 넘기기·전체 화면·상세 격자에 연결돼 있다.

명소 `12`, 문화시설 `14`, 음식점 `39`만 코스에 담는다. 강원도 주소, 제공된 지역·시군 코드, 선택한 시군과 복합 ID의 유형을 대조한다. 최종 코스는 유형 조건도 다시 검사한다. 키워드는 선호에 쓰며 모든 키워드의 동시 충족이나 개인화 추천 순위를 보장하지 않는다.

`locationBasedList2` 반경 검색과 `searchFestival2` 행사 검색은 현재 사용자 흐름에 연결하지 않았다. 과거 API 시험 성공을 기능 구현 완료로 표시하지 않는다.

## 관광사진과 장소 사진의 구분

관광사진 탐색은 제목·촬영지·시군이 같은 사진을 묶어 보여 주고 해당 시군 검색으로 연결한다. 업로드 사진 인식이나 정확한 촬영 좌표 판별 기능이 아니다. 제목·지역을 확인하더라도 `galContentId`를 `contentid`로 바꿔 사용하지 않는다.

장소 카드의 추가 사진은 국문 `detailImage2`에서 해당 `contentId`로 조회한 자료다. 서버는 장소 확인과 이미지 요청을 병렬로 시작하되 장소 검증이 끝나기 전에는 결과를 반환하지 않는다. 반환된 콘텐츠 ID·허용 이미지 주소·중복을 검사한다. 요청당 100장, 최대 10페이지 범위에서 추가 조회한다.

화면은 작은 사진을 먼저 보여 주고 현재 사진의 원본이 준비되면 교체한다. 출처·촬영자·제공된 이용 유형을 표시하고 로드 실패를 처리한다. 원본 해상도나 제공처 다운로드 속도는 서비스가 보장하지 않는다.

## 오디·연관·편의정보 매칭

**오디:** 정규화한 관광지명과 한국어 여부를 확인한다. 양쪽에 좌표가 있으면 2km 이내인지 대조하고, 좌표가 없으면 이름으로만 대조했다는 안내를 남긴다. 원본 대본·음성을 제공하며 AI가 만든 역사나 음성으로 표현하지 않는다. 같은 이름이 있다는 이유만으로 현장 동일성을 완전히 보장할 수는 없다.

**연관 관광지:** `app/tour_api/related_region_codes.json`의 별도 코드표를 사용한다. 여기의 강원 코드 `51`을 국문 코드와 혼용하지 않는다. 현재 설정 기본 기준월은 `202504`이며 응답에 표시한다. 국문 조회에서 정규화한 전체 이름·지역이 맞는 단일 장소만 선택 후보로 연결하고, 없거나 동명이면 연결하지 않는다. 현재 인기·실시간 이동·최단 순서로 해석하지 않는다.

**무장애 정보:** 먼저 같은 ID를 후보로 조회하더라도 유형·이름·주소를 대조한다. 양쪽 좌표가 있으면 200m 이내를 확인한다. 불일치하면 무장애 서비스 자체 지역코드와 이름 검색으로 다시 찾되 여러 장소가 일치하면 연결하지 않는다. 제공된 편의 항목만 표시하며 빈 값은 이용 불가가 아니다. 시설 조건 필터나 여행 가능 여부 판정은 미구현이다.

## 자동차 이동과 실패 처리

현재 순서의 장소 ID를 서버에서 다시 조회하고 인접한 두 장소씩 자동차 길찾기를 요청한다. API 응답의 거리·시간·도로 좌표를 검사한다. 기본 설정은 프로세스별 하루 100회, 동시 2개, 요청 시간 제한 10초, 같은 방향의 성공 구간 캐시 120초다. 공급자 계약상 할당량과 이 애플리케이션의 제한은 별개다.

성공한 구간과 실패한 구간을 구분하고 모든 구간이 성공했을 때만 전체 이동 합계를 표시한다. 실패 구간을 직선 경로나 가짜 시간으로 채우지 않는다. 첫 장소까지의 이동·체류·주차 시간과 최적 방문 순서 계산은 포함하지 않는다.

기본 장소 검색은 병렬 호출 중 하나가 실패하면 전체 요청이 실패한다. 반면 관광사진의 보충 조회, 부가 상세, 자동차 구간은 각각 정해진 부분 실패 처리를 한다. 모든 API가 동일하게 부분 성공을 지원한다고 표현하지 않는다.
