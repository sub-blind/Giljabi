# MVP 사용자 시나리오 (강원 · 투어리즘 Tourism)

팀 규모(2명), 5월 접수·데모, 한국관광공사 OpenAPI 필수, 지역특화(강원)를 전제로 한 **최소 성공 시나리오**다.  
기능 나열이 아니라 **한 명의 사용자가 끝까지 한 번 완주하는 경로**를 기준으로 한다.

### 스택 (레포 구조)

- **앱 이름**: 투어리즘 (Tourism)
- **백엔드**: FastAPI `app/` — `/api/v1/tour/list-by-area` 등 TourAPI 프록시.
- **프론트**: Next.js 14 `web/` — `NEXT_PUBLIC_API_BASE_URL`(기본 `http://127.0.0.1:8000`)로 백엔드 호출, 코스 화면에서 강원 POI 표시. UI는 `storyroute_ai_full_ui_prototype` 계열(다크 윈도우 바·그라데이션·사이드 브리핑 패널)을 따름.

---

## 1. 페르소나 (한 명으로 고정)

- **누구**: 국내 여행을 검색하는 일반 사용자(강원 1박 2일 또는 당일 여행 상상).
- **목표**: “강원에서 뭐 하지?”를 **검색 몇 번으로 끝내고**, 마음에 드는 장소 몇 곳으로 **하루 코스 초안**을 얻는다.
- **제약**: 복잡한 회원가입 없이 **웹만**으로 시작해도 된다(로컬 저장 허용).

---

## 2. 핵심 시나리오 (Happy Path) — 반드시 완주

### 시나리오 A: 지역부터 들어가기

1. 사용자가 서비스에 접속한다.
2. **강원**이 기본 지역으로 잡혀 있거나, 한 번에 강원으로 선택된다.
3. **관광지 목록**(또는 추천 테마)이 보인다 — 데이터는 **TourAPI**(지역기반 목록 등)에서 온다.
4. 목록에서 **한 장소**를 누른다.
5. **상세 정보**(이름, 소개, 이미지, 위치)가 보인다 — TourAPI 상세·이미지 연동.
6. “**이 근처 / 이어서 가기 좋은 곳**” 또는 “**오늘 코스에 넣기**”로 **2~3곳이 이어진 1일 코스 초안**이 생성된다(규칙 기반만으로도 됨).
7. 코스를 **링크 복사** 또는 **로컬 저장**으로 남긴다.

**완주 기준**: 2→7까지 **끊김 없이**, 실제 API 데이터로 동작한다.

---

### 시나리오 B: 말로(키워드) 찾기

1. 사용자가 검색창에 **키워드**(예: “폭포”, “드라이브”)를 입력한다.
2. **강원 범위** 안에서 검색 결과 목록이 나온다 — TourAPI 키워드 검색 + 지역 필터.
3. 이후는 시나리오 A의 4→7과 동일(상세 → 코스 초안 → 저장/공유).

**완주 기준**: 검색 → 상세 → 코스까지 **한 흐름**으로 간다.

---

## 3. MVP에서 의도적으로 넣지 않는 것 (범위 밖)

- 전국 모든 지역을 동일 품질로 커버(강원 우선).
- 소셜 로그인·서버에 계정 저장(필요 시 나중).
- 의미 검색·대화형 AI 플래너 **전부**(나중에 “한 가지”만 추가).
- 실시간 혼잡·빅데이터 대시보드 **전체**(한 줄 카피 수준은 선택).

---

## 4. 심사·제출 관점에서 이 시나리오가 주는 것

- **OpenAPI 활용**: 목록·검색·상세에 실제 호출이 드러난다.
- **지역특화**: 강원 고정/필터가 **서비스의 중심**이 된다.
- **완성도**: “보기만 하는 앱”이 아니라 **코스 초안까지** 가면 기획·완성도 배점에 맞는다.
- **확장성**: 나중에 AI·DB 캐시·계정을 **같은 시나리오 위에** 얹기 쉽다.

---

## 5. 팀 작업과의 대응

| 시나리오 구간 | 데이터 담당 | 앱/서버 담당 |
|---------------|-------------|--------------|
| 목록·검색 품질 | 지역코드, 호출 파라미터, 캐시 여부 결정 | 목록 UI, API 라우트 |
| 상세 | contentId·타입, 이미지 URL 규칙 | 상세 페이지 |
| 코스 초안 | 연관지 API 또는 규칙용 데이터 | 순서·시간 UI, 저장/공유 |

---

## 6. 다음 문서로 이어가면 좋은 것

- 사용할 **TourAPI 오퍼레이션 목록**(KorService2 기준, 이미 코드에 반영된 이름과 대조).
- **강원 areaCode / 시군코드** 확정표(팀 공유용).
- 5월 데모용 **3분 발표 대본**(위 시나리오 A 또는 B 중 하나만 시연).

이 파일은 MVP 범위가 흔들릴 때마다 **“지금 이 시나리오가 아직 되나?”** 로 되돌아보는 기준으로 쓴다.
