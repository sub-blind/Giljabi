# 최소 사용자 시나리오

2026년 9월 17일 · 1인 개발 · 강원도 당일 여행 · 실제 Tourism 저장소 기준

현재 강원특별자치도 전체 검색과 18개 시군 선택을 지원한다. 실제 연결 확인과 미확인 항목은 [검증 기록](VALIDATION.md)을 따른다.

## 완주할 흐름

사용자는 ‘바다도 보고 식사도 하는 하루’를 만들고 싶다. 회원가입 없이 접속하면 ‘조건으로 찾기’가 열린다. 지역과 장소 유형을 고르고, 필요할 때 선호 키워드를 펼쳐 입력한다. ‘문장으로 찾기’나 ‘사진으로 찾기’로 전환할 수도 있으며 한 번에 한 입력 화면만 보인다. 탭을 바꿔도 이전 입력은 유지된다.

문장을 입력하고 해석을 실행하면 같은 검색 영역의 조건 탭으로 이동하며 편집 영역에 초점이 맞춰진다. 사용자는 해석된 관심 유형·키워드를 확인하고 수정한다. AI 연결이 준비되지 않았으면 준비 중 안내에서 직접 조건 선택으로 이동한다. 지역을 이미 정했다면 바로가기에서 실제 장소를 검색할 수 있다.

실제 관광 API에서 강원도의 장소 후보를 조회한다. 강원도 전체 또는 선택한 시군을 기준으로 검색하며, 이름·분류·주소·사진 누락 여부와 근거를 확인하고 상세를 열 수 있다. 최대 세 장소를 고르고, 특정 장소가 마음에 들지 않으면 현재 후보 안의 다른 장소로 바꾼다. 한두 장소로도 완성할 수 있다.

코스 만들기를 누르면 서버가 장소 ID·유형·지역·존재 여부를 다시 검사한다. 실제 소개와 대조한 AI 단서 또는 확인된 사실이 보인다. 사용자는 방문 순서를 바꾸고 지도 마커·방문 순서 점선을 확인한다. 첫 장소로 가는 길찾기와 직전 코스 장소에서 다음 장소로 가는 길찾기를 카카오맵에서 열 수 있다. ‘자동차 이동 확인’을 누르면 서버가 장소를 재검증하고 실제 자동차 예상 이동시간·거리·도로 경로를 조회한다. 순서를 바꾸면 이전 경로가 사라지고 다시 확인해야 한다. 한 장소 코스는 장소 간 이동 구간이 없다. 첫 장소까지의 이동·체류·주차 시간은 포함하지 않는다. 코스를 저장하거나 여행을 시작한다.

여행 시작 후 다음 미방문 장소를 안내하고 직접 방문 체크와 장소별 메모를 저장한다. 방문 체크는 위치 인증이 아니다. 순서를 바꿔도 같은 장소 구성의 기록은 유지한다.

저장한 코스를 다시 열면 실제 장소 정보를 재조회하고 해당 코스의 여행 기록을 복원한다. 조회 실패나 사라진 장소는 안내한다. 코스와 기록은 이 브라우저에만 저장되며 기기 간 동기화나 공유는 제공하지 않는다.

## 사진과 이야기로 발견하기

‘사진으로 찾기’ 탭에서 지역·키워드를 입력하고 조회 버튼을 눌러 관광사진을 둘러본다. 탭을 열기만 해서는 API를 호출하지 않는다. 다른 탭에서는 사진 화면을 숨기되 필터와 조회 결과는 유지한다. ‘이 지역 장소 찾기’로 실제 관광 후보를 검색하며 사진 ID나 촬영지 문자열만으로 정확한 지도 위치를 표시하지 않는다.

장소 상세의 ‘이야기 듣기’에서는 관광지명과 제공 좌표를 대조한 오디 원본 대본·음성을 확인한다. ‘함께 볼 곳’에서는 기준월 연관 자료를 살펴본다. 국문 관광정보에서도 이름·지역을 확인한 장소만 후보로 연결하고 사용자가 직접 선택한다. 조건이 다른 장소를 살펴보면 새 검색 조건을 준비하고 이전 선택 초기화를 안내한다.

## 예외 상황

- AI가 없거나 실패하면 직접 조건을 확인하고 검색한다.
- 관광 연결이 없으면 실제 후보를 제공한 것처럼 표시하지 않는다.
- 빈 결과·사진 없음·좌표 없음·대체 후보 없음은 각 상황에 맞게 안내한다.
- 새 검색이 실패하면 이전 결과와 적용 조건을 유지한다.
- 저장에 실패하면 성공 메시지를 표시하지 않는다.
- 사진·오디·연관 조회 실패나 빈 결과는 해당 영역에서 안내하며 기본 여행 검색을 유지한다.

## 반응형 기준

홈은 별도의 오른쪽 안내 열 없이 하나의 검색 영역으로 구성한다. 모바일은 지역·유형 한 열, 전체 폭 검색 버튼, 지역 바로가기 두 열·두 행을 제공한다. 768px 이상에서는 지역·유형을 두 열로 배치하고 검색 버튼은 오른쪽에, 지역 바로가기는 한 행에 둔다. 키워드와 긴 조건 안내가 펼쳐져도 빈 옆 열이나 가로 넘침이 없어야 한다.

모바일은 장소 카드 한 열과 코스 목록 다음 지도, 선택 단계·여행 중에는 하단 행동 영역을 제공한다. 태블릿은 카드 두 열, 768px 이상 코스 화면은 목록과 지도를 나란히 배치한다. PC는 후보 목록과 선택 목록도 나란히 배치한다. 고정된 휴대폰 틀 없이 같은 기능을 사용할 수 있어야 한다.

## 완료 기준

입력 → 수정 → 실제 검색 → 선택·교체 → 코스 검증 → 순서·지도 → 저장·복원이 이어져야 한다. 서버 저장·공유 링크·전국 지도·사진 인식은 이후 확장이다.

최신 범위는 [개정 기획서](PROJECT_PLAN.md), 실제 파일·API는 [프런트·API 설계서](FRONTEND_API_SPEC.md)를 따른다. 과거의 2인 개발·5월 접수 기준을 현재 일정으로 사용하지 않는다.
