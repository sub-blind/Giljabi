Primary User Flow

사용자 경험은 검색 → 상세 → 플래너 → 저장/공유 흐름을 기본으로 한다.

1. 질의 입력

자연어 검색, chips, 샘플 질의

2. 탐색

리스트 + 지도 + 필터 + 추천 이유

3. 의사결정

상세 정보, 스토리, 주변 추천

4. 일정 확정

일자별 itinerary 생성, 수정, 저장

Screen Blueprints

각 화면은 실제 구현 시 shell 구조를 그대로 따라간다.

Home
Hero copy + 자연어 입력창
Quick chips + 샘플 질의
지역특화 진입 / 최근 저장 itinerary
  • 첫 CTA는 반드시 검색 진입
  • 최근 검색/저장 일정은 2차 정보
Search
Filter sidebar
Result list / reason cards
Map / itinerary preview
  • 필터, 결과, 지도 3열 구조
  • loading / empty / partial error state 필요
Place Detail
Hero image + info + story
Nearby places + reason + add to planner
  • AI 요약과 스토리 카드가 차별점
  • CTA는 일정 추가 / 공유 / 플래너 보기
Planner
Constraint + agent panel
Day-by-day itinerary
Map + distance summary
  • generated / modified / saved 상태 분리
  • MVP는 up/down edit만 지원
Trips / Region
Saved trips / recent rebuild / liked places
Region hero / key places / intent cards
  • Trips는 재사용 허브
  • Region은 공모전 지역특화 포인트
Admin
KPI cards
Top intents / combinations / ingestion status
  • MVP는 desktop 우선
  • fixture 기반 KPI부터 시작
